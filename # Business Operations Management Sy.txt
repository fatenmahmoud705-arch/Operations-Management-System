# Business Operations Management System

A full-stack web application built with **Python (Flask)**, **SQL**, and **Bootstrap**. 
Designed to streamline business operations, employee directory management, and task status tracking.

## Features
- Role-Based Access Control (RBAC) & Password Hashing.
- Full CRUD for Employee & Task Directory.
- Interactive Operational Dashboard.

## Tech Stack
- Python / Flask
- SQLite Database
- HTML5 / CSS3 / Bootstrap 5
